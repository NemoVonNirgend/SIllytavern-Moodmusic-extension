# Changelog

## 3.0.0

- Made the repository directly installable by SillyTavern's server plugin manager.
- Removed deprecated SillyTavern body-parser imports and the Axios dependency.
- Added OAuth state validation and safe callback rendering.
- Added Spotify logout, health, config metadata, normalized playback, and device routes.
- Added request timeouts, shared token refresh, bounded input validation, fallback search, and clearer Spotify errors.
- Added Node 20 metadata, unit tests, current installation instructions, and a synchronized frontend distribution.
